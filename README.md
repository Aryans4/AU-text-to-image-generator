# AI Text-to-Image Generator 🎨

An AI-powered text-to-image generator built with Python and Stable Diffusion. The project provides a web interface and command-line generation workflow for creating images from text prompts.

## ✨ Features

- Generate images from text prompts
- Stable Diffusion v1.5 integration
- Gradio-based web interface
- Command-line image generation
- Multiple image generation options
- Custom image resolution
- Seed control for reproducible generation
- Multiple scheduler options
- Style presets
- Negative prompts
- Automatic device detection
- Support for CPU, CUDA, and Apple Silicon MPS

## 🛠️ Tech Stack

- Python
- PyTorch
- Hugging Face Diffusers
- Stable Diffusion
- Gradio
- Pillow
